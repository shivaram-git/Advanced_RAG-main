Machine Learning Basics
    Machine learning is a subset of artificial intelligence that  enables systems to learn and improve from experience without being explicitly programmed.
    It focuses on developing computers programs that can access data and use it to learn for themselves.

    Types of Machine Learning:
    1. Supervised Learning: Learning from labeled data.
    2. Unsupervised Learning: Learning from unlabeled data.
    3. Reinforcement Learning: Learning through rewards and penalties.

    Applications include image recognition, speech recognition, and recommendation systems.
