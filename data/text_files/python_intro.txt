Python programming Introduction

    Python is a high-level, interpreted programming language known for its simplicity and readability. 
    It was created by Guido van Rossum and first released in 1991. Python has become one of the most popular programming languages in the world.
    Key features :
    1. Easy to Learn and Use
    2. Extensive Libraries
    cross-platform compatibility
    strong community support

    Python is widely used in various fields, including web development, data science, artificial intelligence, scientific computing, and automation.
